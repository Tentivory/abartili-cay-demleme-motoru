# Abartılı Çay Demleme Motoru

## Giriş

Bu proje, insanlığın en temel ihtiyacı olan çay demleme işlemini, bilimsel ve abartılı bir şekilde ele alan devrim niteliğinde bir çalışmadır. Geleneksel çay demleme yöntemlerinin aksine, bu motor çayı **gerçekten demlemez**. Bunun yerine, demleme sürecinin metafizik boyutunu simüle eder. Çünkü bazen çay, sadece su ve yaprak değildir. Bazen çay, bekleyiştir. Bazen çay, sabırdır. Bazen çay, "neden hâlâ demlenmedi" diye bağıran bir iç sestir.

## Bilimsel Temel

Yapılan kapsamlı araştırmalar (ki bunlar hiç yapılmadı) sonucunda, çayın demlenme hızının evrenin genişleme hızıyla doğru orantılı olduğu ortaya çıkmıştır. Bu motor, bu teoriyi pratikte uygular:

1. Su kaynar (teorik olarak).
2. Yapraklar düşünür (varoluşsal olarak).
3. Demlik inat eder (karakter olarak).
4. Çay hazır olur (hayali olarak).

## Kullanım

```bash
python cay_demle.py
```

Program sizden demleme süresini sorar. Ne kadar uzun yazarsanız, o kadar abartılı olur. Önerilen süre: sonsuz.

- ✅ Gerçekten çalışır (teknik olarak)
